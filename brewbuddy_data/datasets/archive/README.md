# Archived datasets (not used by the app)

These Coffee Review specialty-bean CSVs are kept for **research / paper references only**.

The BrewBuddy demo catalog is **`../cafe_menu.csv`** (35 recognizable café drinks) plus images in `images/`.

Do not import these files in the Streamlit UI unless you are experimenting offline. They add obscure origin names and hurt end-user UX.
